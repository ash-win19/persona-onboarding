# Integration demo artwork

These assets label the nonfunctional integration cards. Switches only update React state and reset when the component unmounts. They do not authorize services, send requests, or alter the real Gmail and Calendar connections.

`sources.json` records each asset's download URL and brand reference. SVG marks and wordmarks come from the [SVGL source collection](https://github.com/pheralb/svgl). Google Health uses the original PNG heart from [Google's published marketing assets](https://developers.google.com/health/promote). Wordmark lettering is preserved as vector paths where available; no proprietary font files are bundled. All brand marks belong to their respective owners.
